# MK-TME + 容器隔离原型研究计划

## 研究问题
1. 在同一物理机多容器场景下，如何用 MK-TME 实现“每容器独立内存加密域”？
2. 在容器逃逸/宿主进程读取内存的攻击模型下，容器间机密泄露概率是否可显著下降？
3. 与 TDX 组合时，如何形成“可信启动 + 运行时机密计算 + 容器细粒度隔离”的分层架构？

## 原型创新点
- **双路径执行框架**：真实 syscall 模式 + 可重复 mock 模式，方便论文 artifact 复现实验。
- **容器域密钥编排器**：将“容器 ID -> MK-TME keyid”作为抽象控制平面。
- **攻击自动化评估**：批量扩展容器数并统计跨容器解密成功率。

## 可扩展实验
- 加入 eBPF 采样，观测 key lifecycle 与容器调度事件关联。
- 将容器 runtime（runc/crun）hook 接入 key 分配与释放。
- 增加 TDX quote 验证，证明容器控制面在可信执行环境内部运行。
